Day 1 – November 16

Architecture
Split your application into two services
What you will do:
- Examine your existing code and decide which files belong to Catalog and which belong to Shopping.
- Create the new folder structure:
  - services/catalog/
  - services/shopping/
  - ui/
- Move and adapt the existing Python code into the two independent services.
- Give each service its own FastAPI application and API endpoints.
- Update ADR.md with your new architecture decision (ADR-6).
End-of-day result: You have two separate FastAPI applications instead of one monolithic application.
